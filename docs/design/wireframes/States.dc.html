Every page ships six states

Building only the success case is how a hospital screen ends up blank with no explanation. These are the states each page is expected to handle.

1 · Loading

Announced politely to screen readers. Never a bare spinner with no text.

2 · Success
Wed 10 Sep, 10:20 Cardiology · Dr Okafor

The happy path. The easy one.

3 · Empty

You have no appointments booked.

Book an appointment

Empty is not an error. It says what is true and offers the next step.

4 · Error
! We could not load this

Nothing has changed. You can try again.

Try again

Plain words, no codes, no stack traces. Always a way forward.

5 · Not permitted
You cannot view this page

You are signed in as A. Rahman. This account does not have access.

Go to your home page

Names the account, and offers a way back to work rather than a dead end.

6 · Not found
Page not found

If you typed the address, check it is correct.

Go to the home page

A missing record returns this, never “not permitted” — that would confirm it exists.
